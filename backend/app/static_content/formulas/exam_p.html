1. General Probability (23–30%)

Complement RuleP(Ac) = 1 − P(A)
Addition Rule (General)P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
Addition Rule (Mutually Exclusive)P(A ∪ B) = P(A) + P(B)
Inclusion–Exclusion (3 Events)P(A∪B∪C) = P(A)+P(B)+P(C) − P(A∩B) − P(A∩C) − P(B∩C) + P(A∩B∩C)
Conditional ProbabilityP(A | B) = P(A ∩ B) / P(B), P(B) > 0
Multiplication RuleP(A ∩ B) = P(A|B)·P(B) = P(B|A)·P(A)
IndependenceP(A ∩ B) = P(A)·P(B) ⟺ P(A|B) = P(A)
Law of Total ProbabilityP(A) = Σᵢ P(A|Bᵢ)·P(Bᵢ), for a partition {B₁,…,Bₙ}
Bayes' TheoremP(Bⱼ|A) = [P(A|Bⱼ)·P(Bⱼ)] / Σᵢ P(A|Bᵢ)·P(Bᵢ)
PermutationsₙPᵣ = n! / (n − r)!
CombinationsₙCᵣ = n! / [r!(n − r)!]
Multinomial Coefficientn! / (n₁!n₂!…nₖ!), Σnᵢ = n

Which Counting Tool?

Order matters? Repetition allowed? Tool

Yes Yes nʳ (multiplication principle)

2. Univariate Random Variables (44–50%)

Expected ValueE[X] = Σₓ x·f(x) (discrete) or ∫x·f(x)dx (continuous)
Law of the Unconscious StatisticianE[g(X)] = Σₓ g(x)·f(x) or ∫g(x)·f(x)dx
Variance (Shortcut)Var(X) = E[X²] − (E[X])²
Linear TransformationE[aX+b] = aE[X]+b, Var(aX+b) = a²Var(X)
Coefficient of VariationCV(X) = σ/μ, μ ≠ 0
Limited Expected ValueE[X∧u] = ∫₀ᵘ x f(x)dx + u·P(X>u) = ∫₀ᵘ [1−F(x)]dx
Payment R.V. (Deductible d, Coinsurance α, Limit u)Y = α·[min(X,u) − min(X,d)] = α·[(X∧u) − (X∧d)]

3. Multivariate Random Variables (23–30%)

Marginal pmff_X(x) = Σᵧ f(x,y)
Conditional pmff(x|y) = f(x,y) / f_Y(y)
Independence (Joint)f(x,y) = f_X(x)·f_Y(y) for all x,y
CovarianceCov(X,Y) = E[XY] − E[X]E[Y]
Correlationρ = Cov(X,Y)/(σ_Xσ_Y), −1 ≤ ρ ≤ 1
Variance of a SumVar(aX+bY) = a²Var(X) + b²Var(Y) + 2ab·Cov(X,Y)
Variance of a Sum (Independent)Var(ΣXᵢ) = ΣVar(Xᵢ)
Law of Total ExpectationE[X] = E[E[X|Y]]
Law of Total VarianceVar(X) = E[Var(X|Y)] + Var(E[X|Y])
Max Order Statistic (n iid)F₍ₙ₎(x) = [F(x)]ⁿ, f₍ₙ₎(x) = n[F(x)]ⁿ⁻¹f(x)
Min Order Statistic (n iid)F₍₁₎(x) = 1−[1−F(x)]ⁿ, f₍₁₎(x) = n[1−F(x)]ⁿ⁻¹f(x)
General Order Statistic pdff₍ₖ₎(x) = [n!/((k−1)!(n−k)!)]·[F(x)]ᵏ⁻¹[1−F(x)]ⁿ⁻ᵏf(x)
Central Limit Theorem(X̄−μ)/(σ/√n) → N(0,1) as n→∞
Continuity CorrectionP(X≤k) ≈ Φ[(k+0.5−μ)/σ]

Reproductive ("Sum-Stable") Families — Independent Xᵢ

If X₁,…,Xₙ are independent… …then the sum is
Binomial(nᵢ,p) — common p Binomial(Σnᵢ,p)
Poisson(λᵢ) Poisson(Σλᵢ)

4. Moment Generating Functions

Not always tested directly, but useful for confirming sums of independent random variables (a repeated MGF-product argument underlies every row of the "reproductive families" table above): if X, Y independent, M_{X+Y}(t) = M_X(t)·M_Y(t).

Bernoulli(p)M(t) = (1−p) + pe^t
Binomial(n,p)M(t) = [(1−p) + pe^t]ⁿ
Geometric(p) — trials to successM(t) = pe^t / [1−(1−p)e^t], t < −ln(1−p)
Poisson(λ)M(t) = exp[λ(e^t−1)]
Uniform(a,b)M(t) = (e^tb − e^ta) / [t(b−a)], t ≠ 0
Exponential(λ)M(t) = λ/(λ−t), t < λ
Gamma(α,λ)M(t) = [λ/(λ−t)]ᵅ, t < λ
Normal(μ,σ²)M(t) = exp[μt + σ²t²/2]
